## 一、 Windows 电脑端使用指南

### 1. 任意大文件（如 500MB 视频/压缩包）右键一键分享到手机/Mac
1. 在 Windows 资源管理器中，选中任意文件（支持任意大小）。
2. 点击鼠标**右键** -> 选择 **『发送到跨端传输中心 (SyncHub)』**（Win11 可在二级菜单或直接点击）。
3. 屏幕中央会弹出 **简洁浅色（类 macOS 扁平风格）进度窗口**，显示文件名、大小、上传进度与速度（MB/s）。
4. 上传完成后窗口自动关闭，手机端 `/sdcard/Download` 与 Mac 端桌面 `跨端传输文件` 文件夹会在数秒内自动静默接收该文件。

### 2. 电脑端自动接收来自手机/Mac 的文件
- 后台已注册开机自启无窗守护任务 `SyncHubAutoReceiver`（每 4 秒增量轮询一次）。
- 当您在手机或 Mac 上发送文件后，Windows 会**自动下载并保存在 `K:\跨端传输文件`**。
- 您可以通过以下两个快捷入口直接打开接收目录：
  1. 桌面左下角 **『跨端传输文件』** 文件夹快捷方式；
  2. 桌面顶部 **Glass Folders『系统工具』** 毛玻璃卡片中的 **『跨端传输目录』** 图标。

### 3. 在新电脑上一键重装 Windows 套件
进入交付包 `02_Windows客户端与右键套件` 目录，右键以管理员身份运行：
`一键安装_Windows右键与自动接收.bat`

## 二、 Web 跨端传输与收藏中心 (`https://020814.xyz/hub/`)

可通过桌面『系统工具』卡片中的 **『跨端传输与收藏中心』** 一键打开，或在手机/Mac 浏览器访问 `https://020814.xyz/hub/`。

### 1. 界面布局（类 macOS 简约浅色扁平风格）
- **电脑端**：左侧为 Finder / 备忘录式侧边栏（搜索框、资料库、分类、客户端下载与清理入口），右侧为内容区：顶部是"发送框"，下面是文件 / 文字列表。
- **手机端**：侧边栏收起为顶部的搜索框 + 可横向滑动的分类标签栏；客户端下载、刷新、多选、清理收在右上角 `⋯` 菜单中。
- 视觉统一为白色 / 浅灰底、1px 细分隔线、系统字体、单一蓝色强调色，无毛玻璃、渐变和发光效果。

### 2. 发送文字与文件（统一发送框）
- **发送文字**：在顶部发送框输入或粘贴文字，点击 **发送** 或按 `Ctrl + Enter` / `⌘ + Enter`。文字会同时同步到所有设备的系统剪贴板。右侧剪贴板图标可"读取剪贴板并直接发送"。
- **上传文件**（三种方式任选）：
  1. 点击 **添加文件**（或按 `Ctrl/⌘ + O`）选择一个或多个文件；
  2. 把文件 **拖到页面任意位置**，出现"松开即可上传"提示后松开；
  3. 在页面空白处按 `Ctrl/⌘ + V` 直接 **粘贴截图 / 文件**（截图会自动命名为 `截图_日期_时间.png`）。若粘贴的是文字，会先放入发送框，确认后再发送，避免误发。
- **发送选项**：发送框下方的 **收藏**、**置顶**、**分类** 只对 *下一次* 发送生效，发送后自动复位，不会让后续所有文件都被意外永久保留。
- **上传队列**：右下角（手机为底部）显示传输面板，每个文件独立显示进度、速度和剩余时间；上传中可点 `×` **取消**，失败或取消的文件可点 **重试**。全部完成后面板自动收起；有文件正在上传时关闭页面会弹出提醒。

### 3. 浏览、搜索与分类
- **资料库**：全部、置顶、收藏、**即将清理**（12 小时内到期的普通项目，方便及时收藏保留）。
- **分类**：文档、视频、压缩包、图片、安装包、音频、文本、其他，均显示数量；上传时按扩展名自动识别，也可在项目菜单中随时更改分类。
- **即时搜索**：输入即过滤（不需要回车），匹配文件名、文字内容、分类和来源设备，并高亮关键词。快捷键 `/` 或 `Ctrl/⌘ + K` 聚焦搜索，`Esc` 清空。
- **视图**：右上角可切换 **列表** / **图标**（图片缩略图）视图，选择会被记住。

### 4. 单个项目的操作
- **主操作一键完成**：文字项目显示 **复制**（一键复制到本机剪贴板），文件项目显示 **下载**。
- **收藏 ☆ / 置顶 📌**：每行右侧的星标与图钉为开关按钮，点亮即生效并永久保留；置顶项目固定在列表最上方。取消时如项目已超过 72 小时，会提示"下次清理时会被删除"并提供 **撤销**。
- **快速预览（Quick Look）**：点击项目（或选中后按 `空格` / `Enter`）打开预览：图片、视频、音频可直接播放，文字可完整阅读并复制；预览中按 `←` / `→` 切换上一项 / 下一项，`Esc` 或 `空格` 关闭。
- **更多菜单**：点击 `⋯` 或在项目上 **右键**，可预览、下载、复制下载链接、收藏 / 置顶、修改分类、删除。

### 5. 生命周期（72 小时自动清理 vs 永久保留）
- 每个普通项目都显示到期倒计时（如 `1 天 7 小时后清理`）；12 小时内到期显示为橙色，2 小时内为红色。
- 收藏或置顶的项目显示 **永久保留**，不会被自动清理。
- 侧边栏底部（手机为 `⋯` 菜单）的 **清理临时项…** 会先弹出确认框并显示将删除的数量，只删除未收藏且未置顶的项目，收藏 / 置顶项目不受影响。

### 6. 删除与批量管理
- **删除可撤销**：点击垃圾桶（或选中项目按 `Delete`）后项目立即从列表隐藏，底部提示中 5 秒内可点 **撤销**；5 秒后才真正从服务器删除（关闭页面时会立即提交）。
- **批量操作**：点击 **选择** 进入多选模式，点击项目勾选，可 **全选**、批量 **收藏 / 取消收藏** 或批量 **删除**（同样可撤销），按 **完成** 或 `Esc` 退出。

### 7. 快捷键一览
| 快捷键 | 作用 |
| :--- | :--- |
| `Ctrl/⌘ + Enter` | 发送输入框中的文字 |
| `Ctrl/⌘ + V`（页面空白处） | 粘贴截图 / 文件直接上传；文字放入发送框 |
| `Ctrl/⌘ + O` | 选择文件上传 |
| `/` 或 `Ctrl/⌘ + K` | 聚焦搜索 |
| `N` | 聚焦发送框 |
| `↑` / `↓` | 在列表中移动 |
| `空格` / `Enter` | 快速预览选中项目 |
| `Delete` / `Backspace` | 删除选中项目（可撤销） |
| `Esc` | 关闭菜单 / 预览 / 多选，清空搜索 |

## 三、 Android 手机端使用指南

### 1. 自动接收电脑发来的大文件（已配置 Root 守护进程）
- 手机端若已开启 Root (Magisk)，运行交付包 `04_Android_Root自动落盘套件/install_android_root_synchub.sh`（或在 Web 中心侧边栏底部（手机为右上角 `⋯` 菜单）点击 **『安卓 Root 自动接收』** 下载脚本，在 Termux `su` 下执行）。
- 守护脚本位于 `/data/adb/service.d/synchub_receiver.sh`，开机自动后台静默运行。
- 当电脑右键发送 500MB 文件后，手机会在后台自动流式下载到 **`/sdcard/Download`（系统“下载”目录）**，并通过系统媒体扫描器 (`MEDIA_SCANNER_SCAN_FILE`) 立即出现在文件管理器的“最近下载”中。

### 2. 从手机发送 500MB 大文件到电脑
- **方式 A（最直观）**：把 `https://020814.xyz/hub/` 添加到手机桌面主屏幕（支持 PWA 独立全屏窗口），打开后点击上传区域选择手机里的视频/文件，电脑桌面 `K:\跨端传输文件` 会自动接收落盘。
- **方式 B（系统分享菜单直达）**：在 Android 上使用开源 App **HTTP Shortcuts**，新建一个文件上传 Shortcut：
  - **Method**: `POST`
  - **URL**: `https://020814.xyz/api/hub/upload?device=Android`
  - **Authentication**: Basic Auth (用户名 / 密码见你自己的 `.env` 配置)
  - **Request Body**: `File (Raw binary)`，并添加 Header `X-File-Name: {file_name}`
  - 勾选“在系统分享菜单中显示”，即可在手机相册或文件管理器中点击“分享”一键直传电脑！

## 四、 macOS 端使用指南（SyncHub 菜单栏 App）

### 1. 安装（需要 macOS 12 及以上）
1. 把交付包里的 `03_macOS自动接收与Finder右键套件` 整个文件夹拷到 Mac 上。
2. 打开「终端」，运行 `bash install_mac_synchub.sh`。如果缺少 Xcode 命令行工具，会弹出系统安装窗口，装完按回车继续。
3. 脚本会编译并安装 `~/Applications/SyncHub.app`，停用旧版 LaunchAgent 自动接收以免重复下载（已收过的文件也不会重新下载），装好 Finder 右键菜单，然后启动 App。
4. 第一次启动会打开设置窗口：确认服务器 `https://020814.xyz`，服务器开了账号认证时再填用户名和密码（密码只存在「钥匙串」里）→「测试连接」→「保存」，并允许通知。
5. 编译失败或没有命令行工具时，会自动改用**简易模式**（后台接收 + Finder 右键 curl 上传，和旧版脚本一样）。也可以手动运行 `bash install_mac_synchub.sh --legacy`。
6. 卸载：`bash uninstall_mac_synchub.sh`。已经收到的文件会保留。

### 2. 日常使用
- **菜单栏图标 ⇅**：第一行显示连接状态、上次同步时间和自动接收开关。发送文件时图标旁会显示进度百分比。
- **自动接收**：Windows、手机或网页发来的文件会自动存进 **`~/Desktop/跨端传输文件`**，并弹出系统通知，点通知会在 Finder 中定位到这个文件。同一个文件不会重复下载，同名的不同文件会存成 `名称 (1).扩展名`。可以在菜单里随时关闭或开启。
- **发送文件**：任选一种方式：
  - 在 Finder 中右键文件 → **快速操作 → 发送到跨端传输中心**；
  - 把文件**拖到菜单栏图标上**；
  - 菜单里点 **发送文件…（⌘O）**。

  发送时会弹出白色进度窗口，显示进度、速度和剩余时间，可以取消或重试，全部完成后自动关闭。文件夹会先自动压缩成 zip 再发送。
- **发送剪贴板（⇧⌘V）**：自动判断剪贴板里的内容：文字会发送并同步到各设备的剪贴板，截图转成 PNG 发送，复制的文件直接上传。
- **发送选中的文字**：在任意 App 里选中文字 → 右键 → **服务 → 发送到 SyncHub**。
- **最近项目**：菜单里列出云端最新 8 条。点文字会复制到剪贴板，点文件会下载并打开；按住 ⌥ 时，文件改为在 Finder 中显示，文字改为在网页中查看。
- **设置（⌘,）**：可以修改服务器、账号、接收文件夹，开关登录时启动和通知。

更详细的说明和常见问题见 `03_macOS自动接收与Finder右键套件/README_zh.md`。
